# Reselling Basics: A Beginner Manual for eBay and Amazon Flipping

A plain-English beginner manual for finding items to flip, writing listings,
pricing, shipping supplies, fees, and record keeping on eBay and Amazon. No
experience needed.

This guide is published by **Asdale Dynamics, LLC** (Indiana, formed October
2026), founded by Dylan Asdale — registered nurse turned AI author and founder
of Asdale Dynamics, LLC. It follows the same "explained like a friend would"
style as *The Massive AI Manual* and the hub site dylanasdale.github.io: clear,
warm, step by step, never condescending.

## How to use it

This is a static project — there is no build step, no server, and nothing to
install.

- **Read the manual:** open `docs/manual.md` or `static/manual.html` in any
  browser.
- **Use the printable tools:** open `static/checklist.html` or
  `static/worksheet.html` and print (Ctrl/Cmd + P). The print styles hide the
  navigation and format the page for paper.
- **Run the verification checks:** `./scripts/verify.sh` confirms the LICENSE,
  README credit, HTML files, and internal links are all correct.

## Who this is for

Anyone who wants to start reselling on eBay or Amazon without prior experience.
Written for beginners, in plain English, with step-by-step instructions and
printable worksheets you can fill out by hand.
